# xngl v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build xngl v1: a package that draws `xarray.DataArray` maps with PyNGL through a `Figure`/`Panel` API, with colormaps, TOML styles, shapefiles and a read-only PyNIO xarray backend.

**Architecture:** Public objects (`Figure`, `Panel`, specs, `Colormap`, `Style`) record what to draw as plain Python/numpy data. `fig.save()` hands everything to `xngl.render`, the only package that imports `Ngl`. `xngl.io` is the only package that imports `Nio`.

**Tech Stack:** Python 3.11, numpy 1.x, xarray, PyNGL 1.6.1, PyNIO 1.5.5, netCDF4, cftime, tomllib, pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-10-04-xngl-design.md`

## Global Constraints

- Python `>=3.11,<3.12`; numpy `<2`. PyNGL/PyNIO come from conda-forge, not PyPI.
- Only modules under `src/xngl/render/` import `Ngl`. Only modules under `src/xngl/io/` import `Nio`. Test files may import both.
- xngl never calls `Ngl.end()`. Each figure calls `Ngl.destroy(wks)` in a `finally` block.
- Output paths are made absolute when `Figure` is created (the working directory can change before `save()`).
- Colours are set per plot with `cnFillPalette` (N×4 RGBA array). Never use `Ngl.define_colormap`.
- Locked resources (set only by xngl): `nglDraw`, `nglFrame`, `sfXArray`, `sfYArray`, `nglPanelSave`, and `pmLabelBarDisplayMode` on panels in a shared colour bar.
- Error classes: `XnglError` → `DataError` (also `ValueError`), `StyleError`, `RenderError`. Warnings use `XnglWarning(UserWarning)`.
- Style folder `~/.config/xngl/styles/`; env variable `XNGL_STYLE_PATH` (colon-separated). Search order: `XNGL_STYLE_PATH`, user folder, built-in.
- Tests never use user data paths. Sample data come from the PyNGL install: `<site-packages>/ngl/ncarg/data`.
- Run every command from `/home/puneet/Documents/xngl` with `PY=/home/puneet/miniconda3/envs/pyngl/bin/python`.

## Facts verified during planning (2026-10-04, pyngl env)

1. `Ngl.panel` fails on `None` in the plot list (`'NoneType' object has no attribute 'base'`). An empty panel needs a placeholder: `Ngl.blank_plot` with `tmXBOn/tmXTOn/tmYLOn/tmYROn=False` and `tmXBBorderOn/tmXTBorderOn/tmYLBorderOn/tmYRBorderOn=False` (draws nothing).
2. The blank-plot tick-label overlay is correct only for `CylindricalEquidistant`. It also needs `pmTickMarkDisplayMode="Never"` on the map, or two tick sets appear.
3. `nglPanelLabelBar=True` uses the colours from `cnFillPalette`. `lbBoxEndCapStyle` works in panel resources.
4. `Ngl.panel` restores plot viewports after drawing. Final positions are readable with `Ngl.get_float` only when `nglPanelSave=True`.
5. `txString` in `Ngl.panel` draws nothing. xngl draws the figure title with `Ngl.text_ndc`.
6. `Ngl.open_wks(type, name)` appends the extension; `pdf png eps ps svg` all work. A single frame gives `name.png`, not `name.000001.png`.
7. `Ngl.text_ndc` needs `nglDraw=False` or it draws at (0, 0) at once. Strings: `amZone=0`, `amOrthogonalPosF=-0.5-gap`, `amParallelPosF=-0.5|0|0.5`, `amJust="BottomLeft"|"BottomCenter"|"BottomRight"`, `amResizeNotify=True`.
8. `Nio.open_file(filename, mode='r', options=None, history='', format='')`. Option `MaskedArrayMode="MaskedNever"` returns plain ndarrays. Shapefile variables: `x`, `y`, `segments` (`[start, npoints]`), `geometry` (`[first_segment, nsegments]`) plus attribute variables.
9. NCL named colours: `<site-packages>/ngl/ncarg/database/rgb.txt` (`R G B<tab>name`). Colormaps: `<site-packages>/ngl/ncarg/colormaps` (270 `.rgb`, 22 `.gp`, 8 `.ncmap`).
10. `pytest` and `ruff` are not installed in the pyngl env.

## Planning decisions (within the spec)

- `lat=`/`lon=` of `contour_map` default to the data extent, not the whole globe.
- Panels in a shared colour bar must have explicit, equal `levels` and equal colormaps. `levels=None` in a shared group is a pre-flight error.
- Style option `ticks.outer_only` (bool, default `false`): when true, only the left column shows latitude labels and only the bottom row shows longitude labels. This reproduces the user's scripts.
- Every style implicitly extends the built-in `default` preset, which holds all package defaults. API keywords default to `None`, meaning "take the style value".
- Stipple marker names: `dot`=1, `plus`=2, `asterisk`=3, `circle`=4, `cross`=5, `square`=6, `filled_circle`=16; an int is passed through.

## Review Focus

1. **All-NaN or constant field** → `contour_map` raises `DataError("... contains no finite values")` for all-NaN; a constant field with `levels=None` draws with a warning. Owner: Task 2 (all-NaN), Task 8 (constant).
2. **Lazy, float32 or integer DataArrays** (dask from `open_mfdataset`, `int16`) → converted to float64 numpy without error. Owner: Task 2.
3. **Output path variants**: `"out.PNG"` accepted (case-insensitive), `"out"` or `"out.jpg"` raise `XnglError` at `Figure()`, relative paths resolve against the cwd at `Figure()`. Owner: Task 7.
4. **`save()` called twice** → writes the same file again, no leaked workstations, `resolved_res()` refreshed. Owner: Task 8.
5. **Longitude convention mismatch**: data on 0–360 with `lon=(-20, 40)` → for global data the map draws (cyclic point); for regional data that does not cover the extent, an `XnglWarning`. Owner: Task 2 (detection), Task 8 (render test).
